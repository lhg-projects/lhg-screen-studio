# 蒸馏包 v0.1 — 给别的 AI / 团队用的最小可学载体

## 这个包是干什么的

`reconstructed/`（22 MB）是**给人读的**。`distill/`（约 30 KB）是**给 AI 读的**。

同一个应用，两种投喂方式，效果差 100 倍：

| 投喂方式 | token 量 | 有效信息占比 | 模型表现 |
|---|---|---|---|
| 直接丢 `index.deobfuscated.js`（7.1 MB） | ~200 万 | <15% | 读完开头就飘，输出"看起来懂"的复述 |
| 直接丢整个 `reconstructed/`（22 MB） | ~800 万 | <10% | 超出上下文，或被截断成片段瞎猜 |
| **丢 `distill/` 四份文档（30 KB）** | **~1 万** | **>90%** | 能准确复述架构、按规格实现功能 |

## 包内文件

| 文件 | 给谁 | 用途 |
|---|---|---|
| `01-ARCHITECTURE-1PAGE.md` | 模型 / 人 | 一页纸建立全景，任何后续提问的地基 |
| `02-CAPABILITY-MAP.md` | 模型 / 人 | 「要做 X 功能 → 看哪里 → 关键是什么」映射表 |
| `03-PROMPT-CARDS.md` | 你 | 5 张可直接粘贴的任务卡 |
| `04-BOUNDARIES.md` | 你 / 法务 | 哪些是"学思路"，哪些是"抄资产" |

## 怎么用（三条规则）

**规则 1：不要一次全喂。**
先只给 `01`，让模型复述一遍架构，确认它真的理解了，再给 `02`。

**规则 2：让它"在新代码库里实现"，不是"翻译旧代码"。**
"按规格实现" 出来的东西能用；"把这个 bundle 翻译成 TS" 出来的东西是垃圾——因为它面对的是混淆后的标识符，只能猜。

**规则 3：规格里必须带数值。**
"做一个缩放动画" → 模型给你 20 种方案。
"缩放从 1.0 到 1.8，缓动 cubic-bezier(0.25,0.1,0.25,1)，持续 400ms，触发条件是光标停留超过 600ms 且移动距离 <12px" → 模型给你能跑的东西。

数值在 `reconstructed/src/main/slices/` 和 `reconstructed/src/renderer/` 里，需要定向挖掘（见 `03` 的卡 5）。

## 不要给模型的东西

- 整个 `src/main/index.deobfuscated.js`（噪音淹没信号）
- `src/main/blocks/q5/`、`@sentry/` 等第三方块（与应用逻辑无关）
- 任何 `.js` 原文件（模型会试图"解释"混淆标识符，产出幻觉）
